# docs

Manual procedures that need a human (real microphone, real ChatGPT voice, eyes on the model). Product and
architecture: [../PRODUCT.md](../PRODUCT.md). Rules for changes: [../AGENTS.md](../AGENTS.md).

- [emotion-calibration.md](emotion-calibration.md) — user/assistant prosody and emotion, optional local model.
- [gesture-calibration.md](gesture-calibration.md) — gesture amplitudes, rates and axis signs.
- [semantic-calibration.md](semantic-calibration.md) — reply text on real ChatGPT, timing, density of semantic accents.
- [calibration-wizard.md](calibration-wizard.md) — the automatic real-voice calibration run (Developer Tools →
  Calibration), its ZIP bundle, and the manual checks its ChatGPT automation needs.

When a change adds or alters a calibration or debug procedure, update the matching file here in the same change.
